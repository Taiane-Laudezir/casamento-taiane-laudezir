# Casamento T&L — V8 Mobile

Versão mobile-first do site de **Taiane & Laudezir — 21/11/2026**.

## Objetivo desta revisão

A V7 já estava visualmente aprovada no computador. A V8 mantém o mesmo projeto no desktop e adiciona uma revisão específica para celulares, já pensando no acesso pelo WhatsApp.

## Ajustes mobile aplicados

- Menu adaptado para toque, com fechamento automático e bloqueio de rolagem quando aberto.
- Hero/capa redimensionado para telas pequenas.
- `Taiane & Laudezir` ajustado para não estourar largura.
- Data redimensionada e com melhor espaçamento no celular.
- Seções de história e família empilhadas em uma coluna.
- Banner `O melhor da vida...` revisado para celular.
- Fotos com proporções controladas para evitar cortes ruins.
- Padrinhos em uma coluna, com cards maiores e mais legíveis.
- O Grande Dia reorganizado em cards verticais.
- Botões de mapa ampliados para toque.
- Filtros da lista de presentes em rolagem horizontal.
- Presentes em uma coluna, com botão `Presentear` em largura total.
- Modal de pagamento adaptado ao formato de tela do celular.
- Safe-area para aparelhos com notch/barra inferior.
- Melhorias de acessibilidade e área mínima de toque.
